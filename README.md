# airplane-crash-analysis-powerbi
This project analyzes historical airplane crash data using Power BI to identify trends, patterns, and key factors contributing to aviation accidents. The goal is to create interactive dashboards that provide insights for aviation safety improvements and data-driven decision-making.

## 🚀 Features
- Yearly trend analysis of crashes and fatalities
- Visualization by aircraft type, operator, and location
- Root cause analysis (human error, technical failure, weather, etc.)
- Map of crash locations
- KPIs and safety improvement metrics
